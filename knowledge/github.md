## BehaviorTrace
BehaviorTrace allows users to annotate and label various behavior's whilst wearing an EmotiBit, this allows labelling of those bahvariours which can be used to for training and evaluating machine learning models for future biosignal detection of those behaviours.
Primary language: JavaScript
[Repository](https://github.com/geddie212/BehaviorTrace)

## AppleBehaviorTrace
Apple BehaviorTrace is an experimental iOS and watchOS research prototype for collecting EMA state labels and aligning them with Apple Watch biosignal data.
Primary language: Swift
[Repository](https://github.com/geddie212/AppleBehaviorTrace)
