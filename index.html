How this connects to BehaviorTrace
During training, participant-confirmed activity labels are aligned with time windows. BehaviorTrace extracts features such as mean, standard deviation, minimum, maximum, energy, sample count and timing information across wearable channels. A random forest learns relationships between those features and the labels.
At prediction time, the pipeline selects a new window and computes the same features in the same order. Each trained tree follows feature thresholds to a leaf; their outputs are combined into a predicted activity. The forest does not choose the window itself—the preprocessing pipeline does.
My toy activity project predicted running, walking, sitting and standing. This interactive illustration uses a separate five-tree forest trained on synthetic data; BehaviorTrace’s training script configures 500 trees. Moving across an activity boundary also shows why a window can mix states.

02 / MERGE K SORTED LISTS

      
Divide, solve, merge —
recursion in action.

      
Merge k Sorted Lists (LeetCode 23) is one of my favourite problems from NeetCode: a clean, visual example of divide and conquer. Five linked lists are drawn bottom-up — head at the bottom, next pointing up to ⌀ — each in its own color. Step through it and the heads go into ListNode[] lists, mergeSort splits that array by index, then merge(ls, rs) walks two chains at once and relinks their actual nodes until one sorted chain is left — still carrying every node's original color, so you can see exactly where each one came from.

N = total values across all lists. k = number of lists. Each of the ⌈log₂k⌉ recursion levels merges O(N) values in total, giving O(N log k) time; the call stack itself only ever holds O(log k) frames.

My Java solution (NeetCode · LeetCode 23)
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists.length == 0){
            return null;
        }
        return mergeSort(lists, 0, lists.length - 1);
    }

    public ListNode mergeSort(ListNode[] n, int l, int r){
        if (l < r){
            int m = (l+r)/2;
            ListNode ls = mergeSort(n, l, m);
            ListNode rs = mergeSort(n, m+1, r);
            return merge(ls, rs);
        }
        return n[l];
    }

    public ListNode merge(ListNode ls, ListNode rs){
        if (ls == null || rs == null){
            if (ls != null){
                return ls;
            }
            return rs;
        }

        ListNode curr = new ListNode();
        ListNode head = new ListNode();

        if (ls.val <= rs.val){
            curr = ls;
            ls = ls.next;
        }
        else{
            curr = rs;
            rs = rs.next;
        }
        head = curr;

        while (ls != null && rs != null){
            if (ls.val <= rs.val){
                curr.next = ls;
                ls = ls.next;
            }
            else {
                curr.next = rs;
                rs = rs.next;
            }
            curr = curr.next;
        }

        if (ls != null){
            curr.next = ls;
        }
        if (rs != null){
            curr.next = rs;
        }

        return head;
    }
}
